# ДЧС СКО — памятки по безопасности

Статический сайт Департамента по чрезвычайным ситуациям Северо-Казахстанской области.

## Что внутри
- русская и казахская версии;
- полные изображения памяток без перекрывающих элементов;
- отдельное скачивание памяток в PDF;
- интерактивная проверка дома;
- телефоны 101 и 112;
- официальный Telegram-бот ДЧС СКО;
- QR-код текущей страницы;
- PWA для установки на смартфон;
- офлайн-кэш основных материалов.

## Публикация через GitHub Pages
1. Создайте **Public** repository.
2. Загрузите содержимое этой папки в корень репозитория.
3. Откройте **Settings → Pages**.
4. В **Build and deployment** выберите **Deploy from a branch**.
5. Branch: `main`, Folder: `/ (root)`.
6. Нажмите **Save** и дождитесь публикации.

Файл `index.html` должен находиться именно в корне репозитория.
